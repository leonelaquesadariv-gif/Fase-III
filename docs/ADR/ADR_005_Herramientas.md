# ADR__005: Herramientas de Desarrollo
## Estado 
Aceptado 
## Contexto 
El equipo necesita herraminetas que permitiran desarrollar, documentar y controlar versiones del proyecto de forma colaborativa. 
## Decisión 
Se utiliza las siguientes herramientas:
- Visual Studio Code
- Git 
- GitHub
- PlantUML
- Markdown 
## Justificación 
Estas herramientas permiten desarrollar el proyecto de manera organizada, mantener el control de versiones y elaborar la documentación técnica requerida. 
## Consecuencias 
### Positivas 
- Trabajo colaborativo.
- Control de versiones.
- Documentación organizada. 
- Facilidad para realiazr cambios. 
### Negativos 
- Es necesario que todos los integrantes conozcan el uso básico de las herramientas.
