# ADR__004: Framework de Desarrollo 
## Estado
Aceptado 
## Contexto 
El sistema necesita un framework que facilite el desarrollo de aplicaciones empresariales, reduzca el tiempo de implementación y permita una integración sencilla con la base de datos. 
## Decisión
Se utilizará un framework que facilite el desarrollo de aplicaciones empresariales, reduzca el tiempo de implementación y perrmita una integración sencilla con la base de datos. 
## Justificación 
Spring Boot ofrece: 
- Desarrollo rápido. 
- Configuración automática. 
- Integración con bases de datos. 
- Seguridad.
- Amplia documentación y comunidad. 
## Consecuencias 
### Positivas 
- Menor tiempo de desarrollo. 
- Código más organizado. 
- Fácil mantenimiento. 
- Escalabilidad. 
### Negativas 
- Curva de aprendizaje para nuevos desarrolladores.
