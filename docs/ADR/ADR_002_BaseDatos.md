# ADR_002: Selección de la Base de Datos 
## Estado
Aceptado 
## Contexto 
El sistema almacenará información de estudiantes, cursos, profesores y matrículas. 
## Decisión 
Se utilizará MySQL como gestor de base de datos.
## Justificación 
- Es gratuita.
- Es confiable.
- Tiene buen rendimiento.
- Es compatible con Java.
# Consecuencias 
La información será almacenada de forma segura y organizada.
