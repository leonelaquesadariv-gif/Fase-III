# Sistema Integral de Matrícula Universitaria (SIMU)
## Descripción 
EL Sistema Integral de Matrícula Universitaria (SIMU) es una plataforma diseñada para automatizar el proceso de matricula de estudiantes en una universidad, facilitando la inscripción de cursos, la administración académica y la consulta de información por parte de estudiantes y administradores. 
---

## Objetivo General 
Desarrollar la documentación y el diseño arquitectónico del Sistema Integral de Matrícula Universitaria aplicando buenas prácticas de ingenieria de software. 
---
## Objetivos Especificos

- Elaborar los diagramas UML.
- Documentar las decisiones arquitectónicas (ADR)
- Aplicar el Modelo C4.
