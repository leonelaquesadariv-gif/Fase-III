# Manual de Usuario

# Sistema Integral de Matrículas Universitarias (SIMU)

## 1. Introducción

El presente Manual de Usuario tiene como propósito orientar a los usuarios en el uso del Sistema Integral de Matrículas Universitarias (SIMU).

El documento explica las principales funciones del sistema y proporciona instrucciones para realizar las operaciones más importantes de manera clara, ordenada y segura.

SIMU está orientado a facilitar los procesos relacionados con la consulta de la oferta académica, la matrícula de cursos, la consulta del horario y la gestión administrativa de la información académica.

---

## 2. Objetivo

El objetivo de este manual es proporcionar una guía práctica que permita a los estudiantes y administradores utilizar correctamente el Sistema Integral de Matrículas Universitarias.

El manual describe los pasos necesarios para realizar las funciones principales del sistema y explica las validaciones que se aplican durante el proceso de matrícula.

---

## 3. Usuarios del sistema

SIMU está dirigido principalmente a dos tipos de usuarios:

### 3.1 Estudiante

El estudiante puede utilizar el sistema para:

* Iniciar sesión.
* Consultar la oferta académica.
* Consultar los cursos disponibles según carrera y período.
* Seleccionar cursos para matrícula.
* Realizar la matrícula.
* Consultar su horario.
* Descargar su horario.
* Consultar la información correspondiente a su matrícula.

### 3.2 Administrador

El administrador puede utilizar el sistema para:

* Iniciar sesión como administrador.
* Registrar cursos.
* Modificar información de cursos.
* Gestionar los cursos y sus cupos.
* Consultar información académica.
* Generar reportes de matrícula.
* Exportar reportes en formatos disponibles.

---

# 4. Acceso al sistema

Para utilizar SIMU, el usuario debe disponer de credenciales válidas.

## 4.1 Inicio de sesión

El procedimiento general es:

1. Abrir el navegador web.
2. Acceder a la plataforma SIMU.
3. Introducir el nombre de usuario.
4. Introducir la contraseña.
5. Presionar el botón **Iniciar sesión**.
6. Esperar la validación de las credenciales.

Si las credenciales son correctas, el sistema permitirá el acceso y mostrará las funciones correspondientes al rol del usuario.

Si las credenciales son incorrectas, el sistema deberá impedir el acceso y mostrar un mensaje de error.

### Evidencia

Cuando se disponga de la aplicación ejecutable, se deberá incorporar una captura de la pantalla de inicio de sesión.

---

# 5. Funciones del estudiante

## 5.1 Consultar la oferta académica

La consulta de la oferta académica permite al estudiante visualizar los cursos disponibles para una carrera y un período académico determinado.

### Procedimiento

1. Iniciar sesión.
2. Seleccionar la opción **Oferta Académica**.
3. Seleccionar la carrera correspondiente.
4. Seleccionar el período académico.
5. Ejecutar la consulta.
6. Revisar los cursos mostrados.

El sistema debe mostrar únicamente los cursos correspondientes a la carrera y al período seleccionados.

### Información mostrada

La información de los cursos puede incluir:

* Código del curso.
* Nombre del curso.
* Créditos.
* Grupo.
* Horario.
* Aula.
* Docente.
* Cupos disponibles.
* Prerrequisitos, cuando corresponda.

### Evidencia

Se deberá incorporar una captura de la oferta académica cuando la aplicación esté disponible para ejecución.

---

# 6. Realizar la matrícula

SIMU permite al estudiante seleccionar uno o varios cursos y realizar el proceso de matrícula.

## 6.1 Procedimiento de matrícula

1. Iniciar sesión como estudiante.
2. Acceder a la sección **Matrícula**.
3. Consultar la oferta académica.
4. Seleccionar los cursos que desea matricular.
5. Revisar la información de los cursos seleccionados.
6. Confirmar la matrícula.
7. Esperar la respuesta del sistema.
8. Verificar que la matrícula haya sido registrada correctamente.

---

# 7. Validaciones durante la matrícula

Antes de confirmar la matrícula, el sistema debe validar las condiciones establecidas por las reglas del proyecto.

## 7.1 Validación de prerrequisitos

El sistema verifica que el estudiante haya aprobado los cursos requeridos antes de permitir la matrícula de un curso que tenga prerrequisitos.

Si el estudiante no cumple los requisitos, el sistema debe rechazar la operación y mostrar un mensaje explicativo.

**Ejemplo de mensaje:**

> No cumple con los prerrequisitos del curso seleccionado.

---

## 7.2 Validación de cupos

El sistema debe comprobar que el grupo seleccionado tenga disponibilidad.

Cuando no existan cupos disponibles, la matrícula no deberá completarse.

**Ejemplo de mensaje:**

> El curso no tiene cupos disponibles.

---

## 7.3 Validación de conflictos de horario

El sistema debe comprobar que los cursos seleccionados no tengan horarios incompatibles.

Si dos cursos tienen un horario superpuesto, el sistema debe impedir la matrícula incompatible.

**Ejemplo de mensaje:**

> Existen conflictos de horario entre los cursos seleccionados.

---

# 8. Confirmación de matrícula

Una vez que todas las validaciones son correctas, el sistema debe permitir confirmar la matrícula.

El estudiante debe revisar cuidadosamente los cursos seleccionados antes de confirmar.

Después de completar la operación, se deberá verificar que los cursos aparezcan correctamente asociados a la matrícula del estudiante.

### Recomendación

Antes de confirmar la matrícula, el estudiante debe revisar:

* Curso.
* Grupo.
* Horario.
* Aula.
* Docente.
* Cupos disponibles.
* Prerrequisitos.

---

# 9. Consultar el horario

Después de completar la matrícula, el estudiante puede consultar su horario.

## Procedimiento

1. Iniciar sesión.
2. Acceder a la opción **Mi horario** o la opción equivalente disponible en el sistema.
3. Consultar la información correspondiente.
4. Verificar los cursos matriculados.

El horario debe mostrar la información académica correspondiente a los cursos registrados.

### Información esperada

* Nombre del curso.
* Grupo.
* Día.
* Hora.
* Aula.
* Docente.

### Evidencia

Cuando la aplicación esté disponible, se deberá incorporar una captura del horario del estudiante.

---

# 10. Descargar el horario

El estudiante puede descargar o generar una versión imprimible de su horario.

## Procedimiento

1. Consultar el horario.
2. Seleccionar la opción de descarga o impresión.
3. Esperar la generación del archivo.
4. Guardar el archivo en la ubicación deseada.
5. Abrir el archivo para verificar que la información sea correcta.

El archivo generado deberá contener la información correspondiente al horario del estudiante.

---

# 11. Funciones del administrador

El administrador dispone de funciones para gestionar la información académica del sistema.

## 11.1 Registrar un curso

El administrador puede registrar nuevos cursos proporcionando la información requerida.

### Procedimiento general

1. Iniciar sesión como administrador.
2. Acceder a la sección de gestión de cursos.
3. Seleccionar **Nuevo curso**.
4. Introducir la información solicitada.
5. Revisar los datos.
6. Guardar el curso.
7. Verificar que el curso haya sido registrado.

---

## 11.2 Modificar un curso

Para modificar un curso:

1. Acceder a la gestión de cursos.
2. Buscar el curso correspondiente.
3. Seleccionar el curso.
4. Modificar la información requerida.
5. Guardar los cambios.
6. Verificar la información actualizada.

---

## 11.3 Gestionar cupos

El administrador puede gestionar los cupos asociados a los grupos de los cursos.

Los cambios deben realizarse respetando las reglas de negocio establecidas para el sistema.

---

## 11.4 Generar reportes

El administrador puede generar reportes relacionados con la matrícula.

### Procedimiento general

1. Iniciar sesión como administrador.
2. Acceder a la sección **Reportes**.
3. Seleccionar el período académico.
4. Generar el reporte.
5. Revisar la información.
6. Exportar el reporte cuando corresponda.

---

# 12. Exportación de reportes

Los reportes pueden ser exportados en los formatos disponibles definidos para el sistema.

Entre los formatos contemplados se encuentran:

* PDF.
* Excel.

Después de realizar la exportación, el administrador debe verificar que el archivo se haya generado correctamente y que contenga la información correspondiente.

---

# 13. Mensajes comunes del sistema

| Mensaje                             | Acción recomendada                                            |
| ----------------------------------- | ------------------------------------------------------------- |
| Usuario o contraseña incorrectos    | Verificar las credenciales e intentar nuevamente.             |
| El curso no tiene cupos disponibles | Seleccionar otro grupo o esperar a que exista disponibilidad. |
| Existen conflictos de horario       | Seleccionar un curso con un horario compatible.               |
| No cumple con los prerrequisitos    | Verificar los cursos requeridos antes de intentar matricular. |
| Curso registrado correctamente      | Verificar que el curso aparezca en la información académica.  |
| Matrícula registrada correctamente  | Revisar la matrícula y el horario generado.                   |

---

# 14. Recomendaciones de uso

Para utilizar SIMU de manera segura y adecuada se recomienda:

* Mantener la contraseña protegida y no compartirla.
* Cerrar la sesión al finalizar el uso del sistema.
* Revisar cuidadosamente los cursos antes de confirmar la matrícula.
* Verificar horarios para evitar conflictos.
* Comprobar que los datos de la matrícula sean correctos.
* Utilizar un navegador actualizado.
* Reportar cualquier inconveniente al área correspondiente de la institución.

---

# 15. Solución de problemas

## 15.1 No puedo iniciar sesión

Verificar:

* Usuario.
* Contraseña.
* Conexión a internet.
* Disponibilidad del sistema.

Si el problema continúa, contactar al área de soporte correspondiente.

## 15.2 No puedo matricular un curso

Verificar:

* Prerrequisitos.
* Disponibilidad de cupos.
* Conflictos de horario.
* Estado del curso.

## 15.3 No aparece un curso

Verificar:

* Carrera seleccionada.
* Período académico seleccionado.
* Disponibilidad del curso.
* Información registrada en el sistema.

## 15.4 No puedo descargar el horario

Verificar que el estudiante tenga cursos matriculados y volver a intentar la operación.

Si el problema continúa, contactar al área de soporte.

---

# 16. Soporte y mantenimiento

En caso de presentar inconvenientes durante el uso de SIMU, el usuario debe comunicarse con el Departamento de Registro Académico o con el área de soporte técnico de la universidad.

Al solicitar asistencia se recomienda indicar:

* Nombre del usuario.
* Operación que estaba realizando.
* Mensaje de error mostrado.
* Fecha y hora aproximada del problema.
* Captura de pantalla del error, cuando sea posible.
