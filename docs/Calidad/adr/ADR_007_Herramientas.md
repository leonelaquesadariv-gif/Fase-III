## ADR-007: Herramientas de desarrollo y documentación

**Estado:** Aceptado  
**Decisión:** Utilizar herramientas sencillas y accesibles para el equipo.

| Herramienta | Uso dentro del proyecto |
|---|---|
| Control de versiones y trabajo colaborativo. |
| Visual Studio Code | Crear diagramas | 
| Markdown | Lenguaje para elaboracion | 

### Justificación

Estas herramientas cubren el desarrollo, las pruebas, el diseño, la documentación y el trabajo colaborativo. El objetivo es que cada integrante pueda comprender cómo ejecutar el proyecto y revisar los cambios realizados.

### Consecuencias

El equipo necesitará acordar reglas para crear ramas, realizar cambios, revisar código y actualizar la documentación.

---

## Conclusión

Las decisiones propuestas buscan que el SIMU sea un sistema organizado, seguro y posible de desarrollar por un equipo universitario con conocimientos iniciales de ingeniería informática.

La combinación de **Java, Spring Boot, PostgreSQL, Thymeleaf y Bootstrap**, junto con una arquitectura monolítica modular por capas, permite comenzar con una solución manejable. En caso de que el sistema crezca, la arquitectura podrá revisarse mediante nuevos ADR.
